# Sounds

Drop recorded loops here (for example the ones from Bajá un Cambio) as `rain.mp3`, `waves.mp3`, etc.,
and list them in `manifest.json`:

```json
{ "rain": "/assets/sounds/rain.mp3", "waves": "/assets/sounds/waves.mp3" }
```

Names: rain, waves, wind, birds, storm, thunder, fire, forest, river, night, cafe, horse.
Any name not listed is synthesised in the browser.
